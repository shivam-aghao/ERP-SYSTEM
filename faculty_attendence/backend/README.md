# SSGMCE Faculty Attendance Backend API

Production-ready backend API service for Shri Sant Gajanan Maharaj College of Engineering (SSGMCE), Shegaon.

## Tech Stack
- Runtime: Node.js (ES Modules)
- Framework: Express.js
- ORM: Prisma Client v5
- Database: PostgreSQL (Supabase)
- Validation: Zod
- Testing: Jest & Supertest

## Quick Start
1. npm install
2. npm run prisma:generate
3. npm run prisma:push
4. npm run seed
5. npm run dev
